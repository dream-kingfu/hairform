# 型格 HAIRFORM

面向普通用户的男生 AI 发型分析 H5。当前采用“文字优先、沟通后再选、确认后生成”模式：上传一张正面肖像后，先用一次视觉分析获得完整建议；如果不满意，可以先和发型顾问沟通修改，再选中一款发型或发色并明确确认生成真人预览。

公开项目说明见 [PROJECT_OVERVIEW.md](PROJECT_OVERVIEW.md)。完整运维交接信息只保存在本机忽略文件 `PROJECT_CONTEXT_PRIVATE.md`，不得提交到公开仓库。

应用会提供：

- 最佳短发、最佳中发、最佳长发和一款谨慎选择建议
- 三款正向发型卡可按最新版 `styleId` 查看国内博主真实原帖；只显示平台、作者昵称和 HAIRFORM 自写摘要，不加载平台图片或笔记正文
- 网页结果页支持最多两轮偏好沟通和两次确认修改；后续沟通只发送结构化分析与文字，不重复发送照片
- 默认不调用 Image2；后台开启真人预览后，用户可从三款发型或两款发色中选一款，确认后才生成，整单最多调用 Image2 两次
- 两款可选中生成真人效果的辅助发色色卡
- 更自然的个性化推荐理由，以及 2160×3840 完整 PNG 报告和 1080×1920 WebP 页面预览
- 网页上传前在本地检查清晰度、光线、单人脸、正面角度和构图；确认页以前景完整原图叠加同图模糊背景填满空白，不裁切或拉伸人物，不合格时先提示重拍
- 肖像授权与 AI 处理分开确认并保存任务级确认版本与时间；下载报告同时显示 AI 内容说明并写入可读取的内容元数据
- 24 小时任务保留、匿名反馈、分享与立即删除

## 本地运行

```bash
npm install
npm run dev
```

未配置 Kie API Key 时可通过 `DEMO_MODE=true` 进入演示模式，完整任务流和报告仍可操作，单张预览使用原图作为诚实占位。

Kie 使用文件流上传、异步生成任务和统一任务查询接口。复制 `.env.example` 为 `.env.local` 并填入密钥后启用真实生成：

```text
AI_PROVIDER=kie
KIE_API_KEY=...
KIE_ANALYSIS_MODEL=gpt-5-6-terra
KIE_QC_MODEL=gpt-5-6-luna
KIE_IMAGE_MODEL=gpt-image-2-image-to-image
DEMO_MODE=false
```

文字分析固定支持 Kie Terra、阿里云 Qwen3.6-Flash 和智谱 GLM-4.6V-Flash；沟通改建议独立支持 Kie Terra（GPT）与 Qwen；真人预览固定使用 Kie Image2，质检使用 Luna/Terra。任何白名单外模型都会失败关闭。API Key 只允许保存在本地未提交的环境文件或 Sites 加密环境变量中。

## AI 开发协作

仓库内置可公开复现的轻量协作层：

- `AGENTS.md`：统一角色、代码权限、隐私和交付门禁。
- `.agents/skills/`：HAIRFORM 维护、DeepSeek 开发、多模态验收和发布验收 Skill。
- `.ai-company/`：公共架构、能力路由、任务单和结构化交接模板。
- `.github/workflows/quality-gate.yml`：PR 的 Lint、生产构建和自动化测试门禁。

默认分工是 GPT 负责需求、架构、任务拆解和最终验收，DeepSeek 负责任务单授权范围内的业务代码，确定性工具负责客观检查。这里的 DeepSeek 是开发角色，不会改变 HAIRFORM 线上运行时的模型白名单。

主控电脑专属运维信息继续保存在被 Git 忽略的 `AGENTS.private.md`、`PROJECT_CONTEXT_PRIVATE.md`、`.agents-private/` 或 `.ai-company/private/` 中，不得复制到公开任务、提交和 PR。

## 数据边界

- D1 保存任务状态和结构化分析，R2 保存原图、可选头发蒙版、预览和报告。
- 所有任务都有 24 小时到期时间；读取任务时会清理过期内容，生产环境还应为 R2 配置同等生命周期规则。
- 使用 Kie 时原始肖像会先上传到其临时文件服务。Kie 文档对临时文件删除时间存在 24 小时与 3 天两种描述，正式上线前必须向 Kie 确认实际保留期限，并让隐私指引与真实期限一致。
- 图片、访问令牌和完整模型提示词不会写入业务日志。
- 任务使用高熵访问令牌和 HttpOnly、SameSite Cookie；令牌不进入公开页面 URL。

## 公开部署保护

- 访客 IP 仅以加盐 SHA-256 哈希进入 D1 限流桶，不保存原始地址。
- 默认每位访客每小时最多创建 2 份报告、每天最多 5 份报告。
- 默认全站每天最多 100 个新任务和 200 次 Image2 调用；每份任务最多 1 次 Terra 分析、2 次 Luna 质检、1 次 Terra 疑难复核和 2 次 Image2。
- Kie 积分安全线只在可选真人预览前检查；测试环境可设为 0，正式公开流量应恢复合理阈值。连续服务故障会短时熔断。
- 同一任务使用数据库原子锁防止并发重复处理；达到限额时接口返回 `429` 与标准 `Retry-After`。
- 生产环境必须设置随机 `RATE_LIMIT_SALT`，并可通过环境变量调整全部额度。

## V0.5 先选后生成与自然建议

- 新任务默认采用 `text-first-v1`，一次视觉分析后立即获得文字建议、发色色卡、三款理发师沟通卡和双语报告，不调用 Image2。
- 推荐卡增加基于脸型、发质、发量、发际线和肤色倾向的自然语言解释，不只显示固定标签。
- 发型和发色统一采用“选这款 → 最后确认 → 生成完整预览”的两步交互，避免误触生成。
- 生成成功后自动重排高清报告，包含原图、所选真人效果、个性化理由、发型建议、发色色卡和整体风格。
- `/admin` 为独立密码管理后台，可在 Kie Terra、Qwen3.6-Flash、GLM-4.6V-Flash 之间切换，并控制发型/发色真人预览是否开放。
- 供应商 API Key、`ADMIN_PASSWORD_HASH` 和 `ADMIN_SESSION_SECRET` 必须只保存在 Sites 加密环境变量中；后台不会读取或返回密钥内容。
- 生成管理员密码哈希可在本机运行 `npm run admin:hash-password`，然后把输出值填入 Sites 的 `ADMIN_PASSWORD_HASH`。同时设置至少32字符的随机 `ADMIN_SESSION_SECRET` 和递增的 `ADMIN_PASSWORD_VERSION`。
- 切换供应商前必须先配置对应 Key，并在后台完成一次连接测试；健康结果30分钟内有效。

## V0.6.1 网页对话式修改建议

- 本版本只更新 H5 网页、服务端接口与管理后台，微信小程序保持 V0.5，不包含对话入口。
- 结果页总建议下方新增顾问区，支持自由输入和长度、刘海、打理难度、风格、发色快捷项。
- 顾问会先追问或复述偏好，用户确认后才修改建议；每轮最多沟通两次，每份报告最多完成两次修改。
- 修改模型只能调整目录内的发型、刘海、分缝、发色和理由；脸型、发质、发量、发际线、肤色判断与照片警告由服务端保留。
- 沟通模型与视觉分析模型分别配置，可在 GPT / Kie Terra 与 Qwen 之间切换。功能开关默认关闭，供应商必须已配置且最近 30 分钟连接测试通过才能开启。
- 修改完成后旧报告自动失效，用户重新选款并确认，最终真人图仍由 Image2 生成；开始生成后顾问区锁定。

## V0.6.2 上传确认页修复

- 上传后的照片按原始比例完整显示，不再为了铺满预览区域而裁掉头顶、发际线或两侧画面。
- 网页版本过旧时明确提示刷新，避免新旧页面接口不一致被误报为普通任务创建失败。
- 移除本地人脸模型未加载的冗余长提示，同时保留人脸、角度和构图的服务端复核状态。

## V0.6.3 上传预览自适应填充

- 上传确认页以同一张本地照片生成放大模糊背景，自动填满竖图两侧或横图上下的空白。
- 清晰前景原图继续按完整比例显示，不裁切、不拉伸脸部；两层只复用浏览器 Blob 地址，不增加上传或模型调用。
- 桌面、平板和手机保持原有预览高度与检查面板布局，微信小程序不在本次更新范围内。

## P0 成功率与信任优化

- MediaPipe 人脸关键点检查在独立 Worker 中运行，不阻塞页面；如果浏览器端模型加载失败，会降级到基础检查并由服务端继续复核。
- 照片只有在检查通过、用户分别确认肖像授权与 AI 处理后才上传。HAIRFORM 不把用户照片用作训练数据。
- 服务端会拒绝缺少两项确认或授权版本不一致的任务；授权记录与任务一起在过期或立即删除时清除。
- 选中发型或发色后会完整展示长度、刘海、分缝或明度，只有点击最终确认才生成完整真人预览。
- 生成质检固定检查身份保持、目标匹配、非头发区域保护、伪影、发丝边缘和用户满意度。验收方法见 [PREVIEW_QUALITY_ACCEPTANCE.md](PREVIEW_QUALITY_ACCEPTANCE.md)。
- 下载 PNG 同时带可见 AI 说明与机器可读元数据，避免生成效果被误认为真实染剪照片。
- H5 正向发型卡新增“真实发型灵感”，首批为 15 款目录各核验 1 条抖音原帖；小红书规范链接能力已预留，但未登录网页无法可靠核验具体笔记，因此暂不展示未经确认的候选。
- 灵感目录只保存发型 ID、平台、公开昵称、自写摘要、规范原帖链接和核验日期；不会下载或代理博主图片，不复制笔记，不用于训练、视觉分析、Image2、真人预览验收或 PNG 报告。
- 外链只接受抖音和小红书官方规范域名，禁止短链、查询参数和追踪片段；打开前会明确提示进入第三方平台，失效或异常链接自动隐藏。
